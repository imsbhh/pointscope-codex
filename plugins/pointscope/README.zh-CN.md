# PointScope for Codex · 1.0.2

在 Codex 中圈选前端修改范围、演示操作、连接素材，然后让当前对话理解并修改项目源码。

## 安装

使用 `PointScope-Codex-v1.0.2.zip`，解压到一个保留的目录。安装包顶层有 `安装到Codex.ps1`、本地插件目录和插件市场清单。

Windows：在解压目录中用 PowerShell 运行 `./安装到Codex.ps1`。脚本仅调用当前电脑已有的 Codex，注册本地插件市场并安装 PointScope，不下载运行时。安装后，在 Codex 的插件设置中确认 PointScope 已启用，再开启一个对话使用。已有对话可能需要重新打开才能发现新技能。

也可以在已有 Codex CLI 中运行：

```powershell
codex plugin marketplace add "<解压后的 PointScope-Codex-v1.0.2 目录>"
codex plugin add pointscope@pointscope-local
```

命令已按本机 Codex 的 `plugin --help` 校对。创建插件包不会自动改动个人插件配置；需要执行安装步骤才能在其他项目中调用。

## 开始使用

在目标前端项目的 Codex 对话中输入：

```text
使用 $pointscope 打开当前项目的可视编辑入口。
```

Codex 会复用项目预览，将包内的一个浏览器脚本接入开发入口，并打开内置浏览器。插件不需要另装 Node.js、Python、浏览器扩展、MCP 服务、模型网关或 API Key。项目本身的预览仍使用它已有的开发环境；插件不替代项目的构建工具。视觉理解和源码修改使用当前 Codex 对话的模型及账户能力，模型服务本身并非离线运行。

没有项目时，可以直接打开插件 `assets/demo.html` 体验本地编辑，无需启动服务。磁盘页面通常无法使用原生批注，可保存交接包附加给 Codex。

## 一条工作流程

1. 开启底部的“编辑模式”，选择“元素 / 坐标”；点选、矩形框选或用画笔圈出不规则边界。选中后设置窗口自动出现，窗口可拖动、调整大小，叉掉仍处于编辑模式。
2. 按需调整“范围与样式”“输入响应”“演示笔迹”。采集演示时显示操作轨迹，保留画笔的压力、倾斜等可用证据。
3. 在“想法与素材”中直接查看选区动态预览，填写唯一的修改需求。原来的视觉理解和 AI 交接已合并，JSON / CSS / 响应代码导出收在高级区域。
4. 需要素材时点“节点与文件”，首次自动打包当前修改。把文件拖入节点窗口，连到修改节点，填写文件的作用位置和使用目的。也可以不导入文件，直接交接。
5. 点“交给 Codex”或“交接 N 项修改”，检查交接卡，点“加入 Codex 批注”，在批注编辑器中确认发送。Codex 读取已准备的上下文、显示选区图像，结合素材用途实际修改源码并验证。

## 节点与交接规则

- **修改节点是快照。** 面板中的后续改动不会悄悄覆盖已保存节点。在节点属性中点“用当前选区和想法更新此节点”，或“打包当前修改”新增一个节点。更新保留文件连线，并检查更窄的作用位置仍在范围内。
- 整个画布的交接包含全部修改节点和已连接文件；节点属性的交接只包含该修改及其文件。没有连线的文件不进入本次交接。每条文件连线需要填写用途。
- 交接卡中的内容再次固定。关闭卡片仍可读取该次上下文；重新准备交接会替换旧标识。刷新页面或卸载编辑器会清除内存数据。需要留存时使用“保存工作流”或“保存交接包”。
- 支持旧版 `pointscope-workflow` 1.0 工作流，保留选区、笔迹、节点位置、用途连线和原始文件字节。导入文件是资料，不会在页面执行其中的代码。
- 单文件最大 8MB；工作流最多 40 个节点、100 条连线，图像和文件合计不超过 32MB。交接工具按需分片读取文件；文本摘要每文件最多 12,000 字符、合计最多 40,000 字符，原文件保持完整。

## 原生能力与回退

原生批注和 Site tools 取决于 Codex / Work 的浏览器能力、模型和账户设置，通常需要顶层 HTTPS 或 localhost 页面。插件会检测实际能力；批注请求被接受不代表消息已经发送。页面不会自动发送对话消息。

原生能力不可用时，点击“保存交接包”，将 JSON 附加到当前对话并使用 `$pointscope`。其中包括选区图像、修改配置、操作证据及已连接文件的完整字节，无需再接第三方接口。

动态预览由本地 DOM 生成，遮盖范围外区域和表单内容。画笔圈线内没有完整元素时，自动按坐标保留原轮廓；部分滚出屏幕的选区会显示可见部分。复杂页面优先省略屏幕外的内容；浏览器无法绘制 DOM 时显示标有“简化布局预览”的本地回退图。失败会显示原因，不再持续重试卡住界面，可点击“刷新预览”重试。

1.0.2 保留 SVG 的 `defs`、`use`、局部 `href` / `xlink:href`、遮罩、裁剪、渐变和变换，并将同页的绝对片段引用转为图像内引用。持续动画引起的元素位置变化不会再使每一帧预览失效。无法正确绘制的 SVG 会显示错误，不再把空白替代图报告为“已就绪”。不支持的外部 SVG 资源不会主动下载。

跨域图片、视频、画布或复杂样式可能与屏幕存在差异。此时在“替换预览图像”导入当前视口截图，自动更新会暂停。提交前检查预览和连接文件。

## 自定义快捷键

点击设置窗口标题栏的键盘图标、右键底部工作开关，或按 **Alt + Shift + K** 打开快捷键设置。点击某项按键组合，再直接按新组合键即可绑定。支持清除、取消录入、恢复默认，并检查重复绑定和常见浏览器保留键。

| 操作 | 默认快捷键 |
| --- | --- |
| 切换编辑模式 | Alt + Shift + E |
| 点选 | Alt + Shift + P |
| 矩形框选 | Alt + Shift + B |
| 画笔圈选 | Alt + Shift + L |
| 显示 / 收起设置 | Alt + Shift + O |
| 预览 / 撤销 | Alt + Shift + V |
| 开始 / 停止采集 | Alt + Shift + R |
| 打开节点与文件 | Alt + Shift + N |

设置保存在当前站点的本地存储中，刷新后保留；其他站点需要分别设置。输入框和编辑文字时不触发操作快捷键；采集演示期间只保留停止采集的快捷键，避免中断演示。Esc 保留取消录入 / 关闭窗口 / 退出圈选的作用。

## 包内内容

`plugin.json` 是原生插件清单，`.codex-plugin/plugin.json` 提供兼容清单，`skills/pointscope/` 定义 Codex 工作流程，`assets/pointscope.js` 是自包含浏览器包，`assets/demo.html` 是离线示例。`src/` 保留原生交接、合并面板、预览和快捷键的源码。插件没有外部运行依赖、远程脚本、API Key 配置或模型请求端点。

本包已完成浏览器检查及 Codex 内置浏览器原生交接验证，详见同目录 `验证记录.md`。它是本地安装包，尚未发布到公共插件市场。
